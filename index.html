總覽

首頁總覽 (Overview)

音樂殿堂的儀表板。集中呈現目前音樂庫的專輯總數、曲目數量與 Hi-Res 高解析無損音樂統計，深度整合本機與線上串流：

  • 🕒 最近聆聽 (Recent Played)：自動列出最近聽過的 5 張專輯與完整播放紀錄。
  • 🆕 最近新增專輯：自動同步本機最新匯入與已加入曲庫之 TIDAL 線上專輯。
  • 🌟 每日推薦 (Daily Picks)：依聆聽紀錄自動精選 5 張發燒代表作，每日自動更新。
  • 📖 藝人生活誌 (Artist Spotlight)：隨機探索音樂大師生平歷程、代表作與關聯發燒名盤。
  • 🎤 探索演出者 (Artists)：曲庫演出者卡片隨機抽样，一鍵進入演出者主頁與其專輯。
曲庫瀏覽

專輯、演出者與曲目清單 (Albums / Artists / Tracks)

提供多維度的音樂分類瀏覽與高度自訂視覺配置：

  • 依新增順序排列 (預設)：專輯庫預設以最新新增時間排序，亦支援依專輯名稱 A-Z、演出者 A-Z、發行年份、曲目數與播放次數排列。
  • 封面尺寸切換 (小 / 中 / 大)：專輯庫、演出者頭像、曲風流派與 TIDAL 探索頁的標題列皆提供尺寸切換，自由切換密集緊湊或大器發燒卡片檢視，各頁面獨立記憶個人偏好。
  • 極簡沉浸式元資料：專輯詳情頁於封面右側俐落標示演出者、發行廠牌、發行年份、曲目總數與總時長，免除雜亂底色與框線干擾。
  • AI/關聯推薦擴展：同曲風推薦專輯與關聯演出者自動擴展涵蓋 TIDAL 線上發燒名盤（登入時）。

播放清單

播放清單 (Playlists: 儲存 / 匯入 / 編輯 / 刪除)

在左側選單「播放紀錄」下方的播放清單頁面，自行建立與管理曲目順序：

  • 💾 儲存：播放隊列上方按「儲存清單」，即可把目前隊列的所有歌曲依序存成一個命名清單；也可在清單頁按「新增清單」建立空白清單，或按「加入目前隊列」把佇列附加到既有清單。
  • 📥 匯入 / 匯出：支援匯入 .m3u / .m3u8 / .json 清單檔（不在曲庫中的路徑也會保留檔案路徑，演出者與曲目名稱自動分離還原）；清單也可匯出成 M3U8 給其他播放器，或匯出 JSON 完整備份後再匯入。
  • ✏️ 編輯：清單明細每一首都提供上移 ↑ / 下移 ↓ / 刪除單曲 ✕，播放順序即依你排好的順序；支援重新命名，同名清單不會重複建立。
  • 🗑️ 刪除：可刪除整個清單（只移除清單本身，歌曲仍保留在音樂庫）。
  • ▶ 依序播放 / 🔀 隨機播放：清單內容直接載入播放隊列，本機、獨佔輸出與 DLNA 串流皆適用。

儲存與維護

本機資料夾管理與資料庫維護 (Storage)

管理本機音樂檔案目錄與資料庫備份：

  • 掃描本機資料夾：選取存放無損音訊的硬碟資料夾，引擎將自動批次高速分析 ID3 / FLAC / DSF 元資料與封面圖。
  • 💾 匯出資料庫：將所有已收錄音樂資料夾、曲目母帶元資料、我的最愛收藏及播放次數統計完整匯出為標準 JSON 備份檔。
  • 📥 匯入資料庫：匯入備份資料並執行智慧去重合併。已存在的資料夾與重複曲目將自動略過，並彈出詳細略過報告。
核心發燒功能

音訊路徑與升頻引擎 (Signal Path & DSP Engine)

點擊播放控制器上方的發燒星芒徽章 ⚡ 即可喚起訊號路徑視窗：

  • 左欄（即時音訊路徑）：即時追蹤從「原始母帶音源 ➔ 升頻引擎 ➔ 參數化等化 ➔ 卷積濾波 ➔ DLNA / 本機端點」的各處理節點狀態；作用中的等化器與卷積節點會即時顯示於路徑圖的實際套用位置。
  • 右欄（升頻引擎設定）：
    • PCM 升頻：支援 2x、4x 整數倍頻（推薦相位最純淨）、固定 96k / 192k / 384k DXD 超取樣。
    • 八種濾波器相位：純真還原 FIR（Bit-Perfect 極平坦，通帶 0~21.5kHz 漣波 < 0.0001dB）、線性相位、最小相位、緩衰減混和、高斯長脈衝、高斯最小相位、EXT2 近似，以及 PS-EXT2 直譯 FIR（陡峭滾降、止帶達 -180 dB）。
    • 1-bit DSD 調變：內建 2 / 5 / 7 階諧振噪聲整形 Delta-Sigma 調變器，支援即時轉制為 DSD64 (2.8MHz)、DSD128 (5.6MHz)、DSD256 (11.2MHz) 或 DSD512 (22.5MHz)。
  • 參數化等化器 (PEQ)：獨立於升頻引擎的音色調整，引擎開或關皆可作用（引擎關閉時於原生採樣率處理，不做多餘升頻）。最多 6 段全參數化頻段（低架 / 峰值 / 高架 / 低通 / 高通 / 陷波），內建平直、溫暖厚實、明亮通透、人聲突出、低頻飽和五種音色預設，並支援6 組自訂命名儲存槽一鍵存取個人調校；自動預降保護電路確保任何增益組合都不削頂，頻段設定即時套用到播放中的曲目。
  • 卷積濾波器 (IR 脈衝響應)：載入脈衝響應 WAV 檔案做高精度卷積處理，適用房間校正 FIR、喇叭與耳機校正等應用。採用分割式頻域卷積技術，長脈衝響應也能即時運算；IR 自動重採樣至播放取樣率、單聲道 IR 自動套用左右聲道、響應峰值過高時自動衰減防削頂。處理於參數化等化之後；DSD 來源自動經 24-bit 88.2kHz 降頻路徑套用。
  • 漸進式平行轉換引擎：長曲由最多 8 個平行工作核心同步調變並自動節流穩定 CPU 用量；轉換結果以串流方式邊轉邊推送至端點設備，無需等待整曲轉換完成即可立即開始播放。
串流端點

音訊輸出裝置與網路串流 (Audio Zones / DLNA / UPnP)

無縫推播至客廳串流播放機、擴大機或網路 DAC：

  • 點擊播放控制器右側的「輸出裝置按鈕 (🔊/📡)」，系統將透過 SSDP 自動搜尋區網內的 UPnP/DLNA 渲染器（如 Eversolo、WiIM、Linn 等）。
  • 支援直接輸入 IP 探測，若路由器封鎖 UDP 廣播亦可快速手動連線。
  • 支援原生 DSF 直通、PCM 升頻 24-bit PCM 串流與 PCM ➔ 1-bit DSD 比特流即時推送，DAC 自動鎖定 DSD 時脈。
  • 參數化等化器與卷積濾波同樣適用於網路串流：套用時 PCM 以 24-bit 串流推送、DSD 來源自動降採樣至 24-bit 88.2kHz 處理後推送（引擎 DSD 調變模式下 DSF 直通優先）。
  • 串流採漸進式生成與 HTTP Range / 反壓流量控制：即使轉換速度慢於實時，端點設備也不會卡頓或中斷。
  • 切換曲目或結束程式時，端點設備會立即停止並清空剩餘緩衝音訊。

濾波器相位音質評測報告與 DSD 調變器搭配指南

在數位音訊升頻與 1-bit DSD 調變架構中，升頻濾波器是第一道防線（負責濾除超取樣後產生的鏡像反射 Images），而 Delta-Sigma 調變器是第二道防線（透過高階噪聲整形將量化噪聲搬移至超高頻）。若前級濾波器能乾淨濾除超聲鏡像，調變器的單 bit 比較器便不會產生互調失真（IMD），能獲得最深邃安靜的背景與細膩的高頻空氣感。

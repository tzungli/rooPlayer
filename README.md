這幾天簡直進到一個心流的狀態，好多年沒有這樣認真的做一個程式， 在AI的幫助之下，我製作的roon-like免費音樂管理及播放軟體來了!

我用自己的電腦作算力跑免費AI模型，電腦規格：CPU-AMD 5700X 、顯示卡RTX 5070Ti 16G、記憶體DDR4 64G，用strata跑QWEN3.8-flash-next-iq3xxs大模型，每秒大約55個token。到目前為止已經用掉3.4億個token。

過程中花最多時間的，是與AI討論如何將音樂經過高階調變、濾波器、PEQ等運算之後，高效率的傳到DLNA設備而不產生爆音或斷斷續續。過程中AI重新設計各種升頻數學模型、把平行處理等方法全部拿出來，我學到很多東西。

軟體特點：

1.高度整合本機音樂資料庫及tidal線上資料庫，支援kkbox(但受api限制只能播30秒)

2.與AI合作完全自行編寫的聲音引擎，具備升頻(pcm->dsd)、參數式EQ、卷積濾波器功能。(難怪每個播放軟體聲音都不一樣，因為演算法不一樣)

3.獨家自訂6組濾波器功能，調出你自己想要的聲音。

4.可升頻到DSD512或PCM384K後串流至DLNA設備(如EVERSOLO T8、AURENDER ACS10等)，或原始PCM以DLNA連接HQPLAYER升頻後串流。

5.支援淺色、深色主題。支援動態歌詞。
